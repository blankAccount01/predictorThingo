# Guide
- Main model for prediction is in predict.py
- main.ipnyb tests for differences between categories of projects
- main2.ipnyb is the standard model
- main3.ipnyb tests for different ratios of values
- main4.ipnyb tests for different operations of variables 
- main5.ipnyb tests for different configurations

# Findings
- Model didn't perform significantly better for categories, ratios and operations.
- Configurations only improved it marginally by <1%
- Doing operations of variables is bad cause it is highly dependent on the data you select, so not very reliable.
